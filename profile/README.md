## 🎤 About

**KPOT** is a travel discovery service that maps **K-pop artists to the real-world places they’re connected to** — the café an idol loves, the studio where a music video was filmed, the restaurant a group visited on a variety show.

For global fans, *being a fan* and *planning a trip to Korea* are the same dream. KPOT turns that dream into a route: search an artist, explore their spots on the map, read reviews, and build your own fandom itinerary.

> Built for the **Korea Tourism Data Utilization Competition** (관광데이터 활용 공모전), KPOT reimagines open tourism data through the lens of K-pop culture.

## ✨ Features

| | Feature | Description |
|---|---|---|
| 🔎 | **Artist & Spot Search** | Find artists or places instantly, with recent, popular, and related search suggestions. |
| 🗺️ | **Spot Map** | Browse nearby K-pop spots on an interactive map, filtered by category. |
| 📍 | **Spot Details** | Photos, ratings, reviews, and the artist behind each place. |
| 🏷️ | **Smart Categories** | Restaurant · Cafe · Shopping · Culture · Accommodation · Tourist Attraction & more. |
| ⭐ | **Reviews & Favorites** | Rate spots, leave reviews, and save the places you want to visit. |
| 🙋 | **Personalized Onboarding** | Pick your favorite artists and get a feed tuned to your bias. |
| 📝 | **Community** | Share visits, tips, and stories with fellow travelers. |
| ➕ | **Spot Reporting** | Found a place that isn’t listed yet? Suggest it for the map. |
| 🌐 | **Multilingual** | Fully localized in **Korean · Japanese · English**. |

## 🧩 Tech Stack

**Frontend**

- **React 18** + **Vite 5** — fast, modern SPA tooling
- **React Router v7** (`createBrowserRouter`) for routing
- **CSS Modules** + CSS-variable **design tokens** — a single source of truth for color, typography, spacing, and radius extracted straight from Figma
- **Pretendard Variable** typeface
- Custom **i18n** layer (KO / JA / EN)

**Backend** *(separate repository)*

- **Java 25** + **Spring 4.1.0**
- **JPA** for persistence
- **MySQL** database
- Deployed on **AWS**

## 🎨 Design

KPOT is built on a Figma-driven design system. Every screen maps to a Figma node, and all visual values flow from a shared token file — keeping the product pixel-consistent and easy to scale.

A warm signature red (`#F74C4C`) sets the tone: energetic, friendly, and unmistakably K-pop.
